# 事实与表达边界

## 来源优先级

| 等级 | 来源 | 可以怎么用 |
|---|---|---|
| A | SKU 字段、当前瓶身、有效证书、审核材料、平台导出数据 | 可作为 `[商品事实]` / `[人群包数据]` 直接写，但仍保持原始口径 |
| B | authoritative/methodology KB、已采纳卖点矩阵 | 可按来源写 `[KB:文档名]`，不得扩大结论 |
| C | 用户明确确认的项目决策 | 写 `[项目确认]`，例如“100万人，当前不提纯” |
| D | 从事实推演的生活状态、顾虑、内容判断 | 写 `[创意假设]`，必须允许投放后证伪 |
| E | 食物颜色、味道、演员反应、用量 | 写 `[实测]`；拍完按真实结果更新 |
| F | 尚缺瓶身/证书/资料的品质说法 | 写 `[待审核]`，不得进入正式台词和字幕 |

一句话只能落一个事实层。出现“人群包数据＋创意假设”等混合内容时，拆句再标。

## 人群边界

- 比例只说明构成，不等于每个人都符合。
- 性别年龄不能推导成职业、收入、厨艺、家庭分工或性格。
- 家有儿女不能推导成每天由爸爸做饭。
- 单身不能推导成孤独、凄凉或需要被治愈。
- 城市层级不能推导成住房拥挤、审美落后或消费能力低。
- “愿意买更好的”“担心四瓶太多”“不信广告”若没有直接数据，只能是 `[创意假设]`。
- 人群规模已被项目确认合适时，不把画像宽泛重新解释成“必须提纯”。

## 产品责任边界

生活场景负责共鸣，产品只负责：

- 真实使用方式。
- 套组或规格如何被理解。
- 一个可核验的换购理由。
- 一条已经审核的商品事实。

产品不能负责：

- 消除疲惫或孤独。
- 解决家庭分工、亲子关系或自我价值。
- 让不会做饭的人突然变大厨。
- 自动省时、零失败或适合所有人。

## 调味品常见红线

| 原始事实/主题 | 可以说 | 不可以偷换成 |
|---|---|---|
| 配料表未列白砂糖 | “配料表不含白砂糖” | “无糖”“零糖”“适合控糖” |
| 有机认证 | 审核批准的认证原句、主体、有效期和商品对应关系 | “更健康”“零农残”“儿童/孕妇更适合”“绝对放心” |
| 180 天资料 | 审核材料支持的原始工艺口径 | “所以更香、更鲜、更好” |
| 33 年沿革 | 审核材料支持的品牌/工厂历史口径 | “百年传承”“老字号”“非遗”“三代传承” |
| 500ml×2＋200ml×2 | 当前真实规格 | “一定用得完”“囤着不浪费”“刚好吃多久” |
| 200ml 小瓶 | 这一户在餐桌/味碟的真实用法 | 品牌官方“便携、旅行、更卫生、更保鲜”设计 |
| 本次试吃第二筷 | 本次演员真实反应 | “全家都爱”“孩子更爱吃”“普遍更好吃” |

未审核前不要使用“零添加、无防腐剂、进口、检测合格率、销量、回购率、价格优惠、库存紧张”等表述。

## 证据型脚本开拍卡

开拍前填写：

| 必填项 | 内容 |
|---|---|
| 唯一证据路线 | 配料表 / 有机 / 180 天 / 33 年 / 其他 |
| 当前商品对应 | SKU、瓶身版本、证书主体 |
| 审核允许字幕原句 | 不允许编导自行改写 |
| 文件名与页码/位置 | 可回查 |
| 审核人及日期 | 可追责 |

任一项缺失就取消证据型脚本，换成其他内容类型。不能让演员口播补过证据缺口。

## 案例参考边界

- 国内外案例只拆观看机制、开头、信息推进、产品进入和节奏。
- 不复制他人完整台词、故事或镜头组合。
- 不虚构案例的播放量、转化率、ROI、品牌结论。
- 用户给具体视频并要求反推时，转 `video-reverse`；本 Skill 消费其结构结论，不重复反推。
