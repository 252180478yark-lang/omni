# 京东 Power BI 连接 + 报表指南（2026-06-16）

> 后端数据层已就绪（migration 055 三视图 + 京东数据日级落库）。这份是**老板手动**那截：装 Power BI、连库、建报表。
> 数据层我做完了，Power BI Desktop 是你本机的工具我跑不了，按这个点几下就出报表。

## 0. 一次性准备（约 10 分钟）
1. **装 Power BI Desktop**：Microsoft Store 搜 "Power BI Desktop" → 免费安装（无需登录账号）。
2. 确认 omni 后端在跑（postgres 已配 `restart: unless-stopped`，开机自动起）。

## 1. 连库（PostgreSQL connector，Import 模式）
1. Power BI → **获取数据 / Get Data** → **PostgreSQL database**。
2. 服务器 `localhost:5432`，数据库 `omni_vibe_db`。
3. **数据连接模式选「导入 / Import」**（⚠️ 别选 DirectQuery）。
4. 凭据：Database 方式，用户名 `omni_user`，密码见 `.env` 的 `POSTGRES_PASSWORD`（默认 `changeme_in_production`）。本机无 SSL，弹警告点继续。
5. 导航器里勾选这三个视图（在 `accounting` / `public` schema 下）：
   - `accounting.v_channel_product_margin` —— 三渠道利润测算
   - `public.v_jd_daily_metric` —— 京东销售日报（18 指标）
   - `public.v_bi_cross_platform_daily` —— 抖音 vs 京东对比
   - `public.v_jd_product_top` —— 京东商品带货榜（切片4）
6. **加载 / Load**。

## 2. 三个报表页（拖拽即成）
**页1 · 三渠道利润测算**（数据源 `v_channel_product_margin`）
- 矩阵：行=`product_name`，列=`channel_cn`，值=`gross_profit` / `gross_margin` / `actual_price`。
- 切片器：`channel_cn`、`category`。
- ⚠️ 京东POP/自营的毛利现在大片空白——源价格表里京东这两渠道成本填得稀疏（41行POP仅个位数有保本价）。要补：把京东成本价补进 `accounting.channel_product_costs` 即自动出现。天猫较全（117行66有毛利）。

**页2 · 京东销售日报**（数据源 `v_jd_daily_metric`，长表）
- 折线图：X=`date`，Y=`value`，图例=`metric_cn`（成交金额/订单/买家/曝光/浏览…）。
- 卡片：用度量值筛 `metric_cn="成交金额"` 看最新值。
- ⚠️ **不要行转宽**——长表（date×metric×value）是 Power BI 舒适区，透视它自己来。

**页3 · 抖音 vs 京东对比**（数据源 `v_bi_cross_platform_daily`）
- 折线图：X=`date`，Y=`value`，图例=`platform_cn`，用 `metric_concept` 切片器切 成交金额/订单/买家。
- ⚠️ 看**趋势形态**别硬比绝对值——京东 gmv 与抖音 gmv_paid 口径不完全一致（退款/单位/时点）。

**页4 · 京东商品带货榜**（数据源 `v_jd_product_top`，切片4）
- 表：`rank` / `product_name` / `sales_amt`(引入成交额) / `visitor_cnt`(访客) / `sales_per_visitor`(访客产值)，按 `date` 切片器选当日。
- ⚠️ 每日商品 TOP 快照（page 默认窗口的榜，不是全量商品）；访客字段源数据可能为空。点 `pro_url` 跳商品页。

## 3. 刷新（看新数据）
- 京东数据每天 09:10 由 scout 自动落库（`daily-jd-ingest`），抖音 09:00。
- Power BI Desktop **没有自动刷新**：看数时打开 pbix 点 **刷新 / Refresh**（秒级）即拉最新。
  （想"打开就是新的"再加 Windows 计划任务刷 pbix，单人场景先不用。）
- ⚠️ **京东 session 会过期**：哪天京东日报停更了，是 session 失效——重扫码登录一次（见下）即恢复。

## 4. 三个雷别踩（实测/规划定的）
1. **别选 DirectQuery**（本机小数据无意义 + 将来个人网关不支持）。
2. **别手动装 Npgsql**（connector 内置，手装会覆盖坏掉）。
3. **别在 Power BI 端做单位换算**（金额已是元、rate 0-1、保本价含全部成本——SQL/落库层已固定口径）。

## 5. 京东 session 维护（运维）
京东数据靠登录态抓取，session 会失效（像抖音罗盘 cookie）。停更时让 Claude 重跑
`_jd_login_capture_host.py`（弹窗你扫码登录京麦）→ session 刷新 → 当天数据照常落。
手动补跑当天：`curl -X POST http://localhost:8009/api/v1/scout/jd/ingest`。
