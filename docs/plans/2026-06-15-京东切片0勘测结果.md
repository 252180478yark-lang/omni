# 京东切片0 勘测结果（2026-06-15 实测）

> 老板配合扫码登录后实测产出。切片0 = 摸清「能不能抓、抓哪些接口、什么口径」。**结论：能抓，走轨 A（XHR 回放），无签名墙。**
> 数据来源：HOST 可见浏览器登录 + headed 自动逛 jdsz 商智，录 133MB HAR 蒸馏（HAR 含 token 已删、gitignore）。

## 0. 一句话结论
京东商智业务接口走 **`szgateway.jd.com/api/lowcode/*.ajax`**，**POST JSON、零 h5st 签名**，统一 `{header,body,errors}` 封套 → **scout XHR 回放轨 A 可行**（无需导出按钮轨 B）。登录态已存，37 个业务接口已摸清。

## 1. 登录（已完成）
- **session 已存** `services/scout-agent/sessions/jd/storage_state.json`（gitignore）。
- 登录态 cookie = **`thor` + `pin`**（京麦商家，**不是**消费者 `pt_key`/`pt_pin`）。
- 工具 `_jd_login_capture_host.py`（HOST 可见浏览器，老板在弹窗里京麦扫码；容器 xvfb 浏览器老板看不见、且商家域反爬不能用）。
- 入口链：`shop.jd.com/jdm/home`（京麦后台，登录后）→ 跳 **`jdsz.jd.com`**（这个店的商智，**不是**规划假设的 sz.jd.com/sz-online）。

## 2. 两个网关（别混）
| 网关 | 用途 | 形态 |
|---|---|---|
| `sff.jd.com/api?api=dsm.*` | 京麦**框架/导航/菜单**（`dsm.shop.pageframe.*`/`menu.*`/`navigation.*`）| 非业务数据，忽略 |
| **`szgateway.jd.com/api/lowcode/*.ajax`** | **商智业务数据**（成交/流量/商品/概况）| 轨 A 目标，POST JSON 无签名 |

## 3. 响应封套（所有 szgateway 接口统一）
```json
{"header": {"code": <int 业务码>, "desc": "<str>"},
 "body":   {"data": <对象或数组，真实数据>, "size": <int>, "cache": <bool>, "traceId": "...", "uuid": "..."},
 "errors": null}
```
抽取器：`biz_code_field = "header.code"`（0/200=成功），数据读 `body.data`。

## 4. 首批核心接口 + 实测真实 payload（切片2 直接用，日期换模板）
全部 `POST https://szgateway.jd.com/api/lowcode/...`，Content-Type application/json。

- **经营概况·实时核心指标** `indexSummary/summary.ajax`
  `{"realtime":true,"interval":"SECOND","dateType":"todayRealtime","startDate":"<今日0点>","endDate":"<此刻>","compareStartDate":"<昨日0点>","compareEndDate":"<昨日同时>","compareType":"hb","page":1,"pageSize":1,"indicators":[<指标码数组>]}`
- **概况趋势** `indexSummary/trend.ajax`（同上 + `interval:"HOUR"`,`groups:["dt"]`,`attributes:["dt"]`,`trendType:"segment"`）
- **交易汇总（日级·含同行对比）** `tradeSummary/summary/getSummary.ajax`
  `{"realtime":false,"interval":"DAY","dateType":"day","startDate":"<昨日>","endDate":"<昨日>","compareStartDate":"<前日>","compareEndDate":"<前日>","compareType":"hb","channel":"all","indicators":[...含 ##industry/##preIndustry 同行项]}`
- **流量核心（含同行 peerSwitch）** `flowSummary/getCoreSummary.ajax`
  `{"realtime":false,"interval":"DAY","dateType":"day","startDate":"<昨日>","endDate":"<昨日>","compareStartDate":"<前日>","compareEndDate":"<前日>","compareType":"hb","channel":"all","peerSwitch":true}`
- **商品成交 TOP** `indexSummary/analysis/getProductList.ajax`
  `{"proType":"spu","requestType":"tradeTop","startDate":"<今日0点>","endDate":"<此刻>","realtime":true,"dateType":"todayRealtime"}`

另 32 个业务接口（流量来源 `flowSource/*`、商品360 `product360/*`、行业 `getIndustryHead/getIndustryTopTable`、店铺等级 `shopLevel/getShopStars/targetState`、品牌 `tradeConstBrand/getBrandTable` 等）见蒸馏报告（37 个全集）。

## 5. 口径（指标码体系）
指标码形如 `jdr_sch_trade_deal_ord_ord_amt_sz_trade_deal_snapshot`（成交金额）、`jdr_sch_traffic_brow_sku__page_cnt_..._bsg`（流量浏览）；`##compare`/`##compareValue`/`##industry`/`##preIndustry` 后缀=环比/同行。
**全量口径字典**走框架接口 `szgateway.jd.com/api/common/getDims.ajax` + `getModelFunc.ajax`（返回该店可用维度/指标全集）——切片2 写抽取器前先拉这两个落口径映射表（对齐抖音 gmv_paid，京东指标命名带「京东」限定，见规划决策2）。

## 6. ⚠️ 反爬（切片2 首要风险）
`jdsz/sz-online/szgateway` 对**自动化/headless 浏览器** TLS 层 `ERR_CONNECTION_CLOSED`，**只有真人驱动的真 headed 浏览器过**（老板登录那次 + headed 自动逛过了；headless 必挂）。
→ **切片2 首验**：scout 容器 **xvfb-headed** 回放（runner.js 在已加载页内 fetch）能不能过 jdsz 反爬。过 = 轨 A 成；不过 = 退而用「host headed + session 定时跑」或导出轨。`_jd_survey_session.py`（改 headed）已证 host headed 可过。
