# 调研截图收件箱

## 这是什么

调研抖店各数据源时，老板把截图放到这里 → 在 Claude Code 里告诉路径 → Claude 用 Read tool 读图。

## 命名约定

```
{数据源缩写}-{序号}.png

例如：
  罗盘-01.png        抖店罗盘首页菜单
  罗盘-02.png        商品分析详情页
  千川-01.png        计划列表
  千川-02.png        某计划详情
  云图-01.png        人群洞察首页
```

## 推荐工作流（任选其一）

### 方式 A：Windows 自带（不装软件）

1. **Win + Shift + S** 截图（自由选区）
2. 截图浮窗右下角点开 → Snipping Tool 应用打开 → **Ctrl + S** 另存为
3. 选目录到 `E:\agent\omni\docs\路径A-抖店MVP\screenshots\`，文件名按上面约定
4. 在 Claude Code 里说："看 screenshots/罗盘-01.png"

### 方式 B：Snipaste（推荐，最快）

1. 装 Snipaste（免费，[snipaste.com](https://snipaste.com/)）
2. **F1** 截图 → 截完按 **Ctrl + S** 直接弹保存对话框
3. 默认目录设为 `E:\agent\omni\docs\路径A-抖店MVP\screenshots\`
4. 之后每次只要 F1 → Ctrl + S → 输文件名 → 完成

### 方式 C：浏览器扩展

Chrome 装"网页截图"类扩展，截图后默认保存到下载目录，再手动移到 screenshots/。

## 不截图也行

如果某个菜单结构简单，**直接口述/打字**也可以：

```
你说："罗盘首页左侧菜单：商品分析 / 流量分析 / 客户分析 / 直播分析 / 内容分析"
Claude 就直接记。
```

通常做法：

- **菜单结构** → 口述就够（树状几行）
- **数据字段表** → 截图更快（一图胜千字）
- **图表样式** → 截图

## 截图无须永久保存

调研完成后这些截图就**没用了**——所有信息已经被提取到 `00-调研-抖店数据与动作全景.md` 里。
可以全部删除或归档到压缩包。`.gitignore` 已经把 `screenshots/*.png` 加入忽略，不会进 git。
