## 一、第一天：配置（约 30 分钟）

### 1.1 SKU 配置（v1.5：完全自动，你不用做任何事）

**v1.5 升级**：之前需要你"手动选 5 个 MVP SKU + 填商品 ID"——**这个步骤已经完全砍掉**。

**系统现在自动做这些**：
1. 你完成扫码登录后（§1.2），系统自动跑 g-list runbook，把抖店后台**全店 41 SKU**主数据同步到 `mvp_sku` 表
2. 系统自动维护一个**重点池**（约 9 个 SKU 跑深度抓取），规则：
   - **主推 5 个**：最近 30 天用户支付金额（gmv_paid）TOP 5
   - **衰退 2 个**：连续 3 天 gmv_paid 下行 + 30 天同比下滑最严重的 2 个
   - **新品 2 个**：上架 ≤ 30 天且当日流量最大的 2 个
3. 重点池**每周日 23:00 自动重排**——SKU 状态变了系统自动跟进，你完全不用管
4. 如果你想强制把某个 SKU 钉在重点池里（比如新出了个想重点盯的款），到 SKU 详情页点"⭐ 锁定为重点池"即可（最多锁 5 个）

**非重点池 SKU 怎么办？**
- 全部 41 SKU 都有**核心日报数据**（GMV/UV/客单/退款率等）
- 但只有重点池 SKU 跑**深度数据**（罗盘 product-detail 7 Tab + 云图 SPU 5A + 商品级心智）
- 你打开任意非重点池 SKU 的详情页时，系统**按需触发**深度抓取（首次打开 30 秒 loading）

**所以 §1.1 你需要做的事**：什么也不用做，去做 §1.2。

---

### 1.2 三平台扫码登录（v1.4）

**做 3 次（罗盘+抖店后台 1 次 / 云图独立 1 次），之后系统会自动维持登录态 7 天**。

**1.2.1 抖店罗盘 + 抖店后台（共用一套 cookie）**

1. 打开 `/scout` 页面
2. 看到顶部红色提示条「抖店登录态未配置」→ 点「立即扫码登录-抖店」
3. 系统会弹出一个浏览器窗口（**不要关闭它**），自动跳到罗盘登录页
4. 用手机抖店 App 扫码
5. 看到罗盘首页 → 系统自动检测 + **同步检测抖店后台**（同账号）→ 提示"登录态保存成功（罗盘+抖店后台）"
6. 浏览器窗口可以关闭

**1.2.2 巨量云图（独立账号，可能与抖店账号不同）**

1. 在 `/scout` 看到「云图登录态未配置」→ 点「立即扫码登录-云图」
2. 弹出浏览器窗口，自动跳到 yuntu.oceanengine.com 登录页
3. 用手机抖音 App 或巨量引擎账号登录
4. 进入云图后看到首页（确认右上角品牌已切到 WADAKAN/和田宽 / 食品饮料）→ 系统自动检测 → 提示"登录态保存成功（云图）"
5. 浏览器窗口可以关闭

**之后每 7 天**，系统会通过站内通知（+ 浏览器原生通知，如配置了企微也会同步推送）告诉你"扫码续期 - 哪个平台"——重复上面相应步骤即可。

### 1.3 通知配置（v1.5：完全可选，跳过也能用）

**v1.5 改造**：通知现在采用 **NotificationChannel 抽象**，4 种通道按需启用：

| 通道 | 默认 | 配置要求 | 适合场景 |
|---|---|---|---|
| **站内通知**（inapp）| ✅ 始终启用 | 无 | 你打开 omni-vibe 时看到右上角通知铃 |
| **浏览器原生通知**（browser_push）| ✅ 始终启用 | 首次访问时浏览器弹出"允许通知"对话框，点"允许" | 即使 omni-vibe 不在前台也能收到 |
| **企微 webhook**（wecom）| ⚠️ 可选 | `.env` 写入 `WECOM_WEBHOOK_URL`（任意时刻补） | 想在企微群里看到告警 |
| **邮件**（email）| ⚠️ 可选 | `.env` 写入 SMTP 配置 | 想留邮件存档 |

**MVP 阶段直接跳过**——站内通知 + 浏览器通知就够用。

**后续想接企微？**（任意时刻可以做）：
1. 企微群（"Omni 巡店告警"）→ 群设置 → 群机器人 → 添加机器人 → 复制 webhook URL
2. 把 URL 发给研发，写进 `.env` 的 `WECOM_WEBHOOK_URL`
3. **重启 scout-agent 即生效，无需改任何代码**
4. 测试：在 `/scout` 页面点"发测试通知"按钮 → 企微群收到 = 成功

### 2.2 怎么处理 3 类卡片

#### 🔴 红色（紧急异动）

例如「SKU-A001 GMV 连跌 4 天」：

**你的动作**：
1. 点这张卡 → 跳到 SKU 详情页
2. 看「概览」Tab → 趋势图找掉的拐点（比如发现 4/26 开始跌）
3. 看「动作」Tab → 看 4/26 那天前后做了什么变更
4. 切到「AI 诊断」Tab → 点「启动深度诊断」
5. 等系统拉数据 + 圆桌讨论（约 1-2 分钟）→ 看 AI 给的诊断和建议
6. 觉得对的建议 → 点「采纳」（系统自动建一条待执行的动作）
7. 你去抖店后台执行那个动作（改主图/换素材等）
8. 回 omni 系统点「+ 登记动作」记录刚才做了什么

#### 🟡 黄色（待办）

例如「SKU-A003 待回复：4/24 圆桌建议」：

**你的动作**：直接点 → 跳到决策日志详情 → 阅读建议 → 采纳/拒绝/暂缓

#### 🟢 绿色（已生效）

例如「SKU-A005 主图改版生效：CVR +50%」：

**你的动作**：
- 5 秒看一眼数字，享受一下成就感
- 决定要不要把这个成功打法**复用到其他 SKU**
- 决定后在「动作」Tab 把那条成功动作标记为"可复用策略"

## 四、动作登记（v1.4 双轨：你登记 + 系统抓取）

**为什么必须登记**：登记 = AI 学到东西。不登记，AI 永远不知道你做了什么，下周给你的建议永远是旧的。

**v1.4 升级**——系统现在会**自动抓取**抖店后台的多种操作（库存变更 / 评价回复 / 活动报名 / 内容发布 / 营销工具变更）+ 云图 5A 人群包变更 + 触点结构调整，**你不用重复登记这些**。系统看到你登记时会顶部提示："我已经抓到 X 条今天的动作，你只需补充原因"。

### 4.1 什么动作要登记？（v1.4 12 大类）

| 动作大类 | 子类型示例 | 双轨情况 |
|---|---|---|
| **product 商品类** | 上下架 / 改库存 / 组合套装 / SKU 规格 | ✅✅ 系统抓抖店后台库存变更记录 |
| **asset 资产类** | 主图 / 详情页 / 标题 / 主推视频 | ✅+ 部分需手登（图片改动系统看不到） |
| **price 价格类** | 调价 / 限时折扣 / 满减 / 券 / 大促报名 | +✅ 系统抓活动广场 + 营销工具记录 |
| **service 客服售后物流** | 评价回复 / 售后审批 / 仓配 / 包装 / 售后政策 | ✅✅ 系统抓评价管理 + 售后工作台 |
| **brand_strategy 品牌策略** ⭐ | 触点结构调整 / 6 场景化策略执行 | +✅ 系统看云图触点效能 / 5A 流转 |
| **content 内容类** | 短视频 / 直播 / 直播间挂车 / 推荐卡 / 智能托管 | +✅ 系统抓 content-tool-* 发布历史 |
| **campaign 营销大促** | 大促作战（报名/备货/调价/调券） | ✅✅ 系统抓活动广场记录 |
| **user_reach 用户触达** | 短信 / 站内消息 / 会员权益变更 / 用户分群 | +✅ 系统抓抖店后台-用户触达记录 |
| **audience 人群类** ⭐ | 5A 人群包新建 / 投流绑定 / 目标人群诊断 | +✅ 系统抓云图人群列表 |
| **ad 投放类** | 千川计划 / 出价 / 定向 / 素材（仅登记） | ✅+（千川数据移出 MVP，仅手登）|
| **talent 达人合作** | 百应建联 / 寄样 / 直播预约 / 联盟比例 | ✅+（联盟移出 MVP，仅手登）|
| **shop_ops 全店运营** | 店铺装修 / 店铺政策 | ✅+ 低频，可补登 |
| 系统/AI 自动改的（已自动登记） | / | × 不重复登记 |

**双轨标记**：✅✅ = 双轨都有；✅+ = 主登记 + 后台兜底；+✅ = 后台为主 + 用户补登原因

### 4.2 系统主动抓到的动作怎么处理？

打开 SKU 详情页「动作」Tab 你会看到：

| 标记 | 含义 | 你需要做什么 |
|---|---|---|
| 👤 user_manual | 你手动登记的 | 已完整 |
| 🏪 shop_admin_log | 系统从抖店后台抓的（库存/评价回复/活动/内容） | 点动作 → 系统弹"补充原因"提示框 → 写一句"为什么这么做" |
| ☁️ yuntu_log | 系统从云图抓的（5A 人群包/触点结构）| 同上 |
| 🌐 compass_log | 系统从罗盘抓的（极少）| 同上 |

**关键**：抓到的动作只有"做了什么"，没有"为什么做"。**你的补充就是 AI 学习的关键**。

### 4.2 怎么登记？

**入口**：
- SKU 详情页右上角「+ 登记动作」（推荐）
- 工作台页面右上角快捷入口（任意 SKU）

**填写**（≤60 秒）：

| 字段 | 怎么填 |
|---|---|
| SKU | 默认当前页 SKU |
| 资产类型 | 下拉选「主图 / 详情页 / ...」 |
| 变更描述 | 一句话："新主图突出零添加场景" |
| 截图 | 拖一张改后的截图进去 |
| 优化意图 | 下拉选「提升点击 / 提升转化 / 提升体验分 / 改善 5A 流转 / ...」 |
| 期望影响 | 多选「CTR / CVR / 5A 拉新 / 5A 复购 / 联想量 / 美誉度 ...」 |

**提交后**：
- 立即可见在「动作」Tab
- 7 天后系统自动跑前后对比，告诉你这个动作有没有效果

### 4.3 多个动作叠加怎么办？

**强烈建议：一次只动一个变量**。
- 周一改主图（登记）→ 周三再改详情页（再登记）
- **不要**周一同时改主图+详情页+人群包，否则归因不出来

如果实在要并改：登记每个动作，但系统会标这周的对比卡为 `inconclusive`（无法归因），你心里有数即可。


### 5.2 逐条看 5 条已验证的决策

```
点开一条：
- AI 当时建议什么
- 你做了什么动作
- 7 天后效果（前后对比卡）
- verdict 是 positive / negative / neutral
```

### 5.3 标记成功案例

正向的决策 → 在动作详情页点「归档为可复用策略」+ 写一句话总结：
- "主图突出零添加 + 妈妈手绘风 → CVR +50%"

这些会进入"成功案例库"，下周 AI 给建议时会自动引用。

### 5.4 标记失败教训

负向的决策 → 写一句话原因：
- "低估了人群偏好差异，主图风格太年轻化与本款定位偏差"

### 5.5 处理待执行的 3 条

把还在 pending 的决策清空：
- 能采纳的采纳
- 不打算做的拒绝（写原因）
- 想观察的暂缓（设下周日提醒）

## 七、FAQ

### Q1：登录态又过期了，怎么办？

A：系统会通过 NotificationChannel 推送（默认走站内通知 + 浏览器原生通知；如已配置企微也会推企微）。打开 `/scout` 点对应平台的「扫码续期」按 §1.2 步骤重新扫码即可。失败的当天数据会自动重新跑。三平台分别：
- 抖店罗盘 + 抖店后台共用 cookie，一次扫码两平台同时恢复
- 巨量云图独立登录，需另扫一次

### Q1b：6 场景化策略卡上写"<行业 → 增加投流"，但我不投千川怎么办？（v1.4）

A：投流不是唯一方式，"拉新场景 < 行业"还可以通过：内容拓圈（短视频题材外延）/ 直播预热 / 联盟达人合作 / 站内活动报名（焕新季 / 618）等多种方式。云图触点效能页可以看到你**当前的投放结构**——如果通投占比 100%，说明你确实只用了一种方式，可考虑分散到品牌广告 / UGC 互动 / 达人营销。

### Q1c：5A 心电图卡的"超过同行 X%"是什么意思？

A：云图把你品牌的 5A 资产规模和**食品饮料行业同等品牌**做对比。比如 A3 问询 6,293 (超同行 74.7%)，意味着你的 A3 人群规模超过了 74.7% 的同行品牌。这个数字是**你的相对位置**——不是绝对好坏，而是和同类品牌比是高还是低。

### Q2：异动卡片说我 SKU 跌了，但我去抖店后台看是涨的？

A：检查这 3 件事：
1. 系统取的是**昨天**数据，你看的可能是**今天**实时
2. 数据库时区是 Asia/Shanghai 还是 UTC（让研发查）
3. 罗盘后台的"成交金额"和系统的 gmv 字段映射是不是一致

### Q3：AI 给的建议太空泛/不对症？

A：两种处理：
1. 拒绝时填详细原因 → 系统会调整（路径 B 阶段才完整生效）
2. 启动「圆桌讨论」 + 自定义议题 → 比异动自动诊断准

### Q4：截图上传失败？

A：检查：
- 文件大小 ≤ 5MB？
- 格式是 jpg/png？
- 网络是否通到 omni 服务？
- 不行的话先 skip 截图字段，纯文字描述也行

### Q5：登记了动作但 7 天后没看到验证结果？

A：可能原因：
1. 那 7 天内有其他动作叠加 → verdict = inconclusive
2. cron 没跑（让研发检查 02:00 任务）
3. SKU 在那 7 天内停售 / 下架，无数据

### Q6：周末复盘可以省掉吗？

A：**不建议**。复盘 5 分钟换来的是：
- AI 学到你的偏好
- 成功案例沉淀
- 失败教训不重蹈

这 5 分钟是飞轮转起来的关键投资。

### Q7：今天抖店罗盘改版了，所有 runbook 都失败？

A：
1. 系统会通过 NotificationChannel 推送告警（站内 + 浏览器；可选企微）
2. 工作台首页显示红色横条
3. 短期临时方案：手动从罗盘导出 CSV → 通过 `/scout/upload-csv` 上传
4. 中期方案：让研发更新 runbook selector（30 分钟工作量）

### Q8：能换个店来跑吗？

A：路径 A MVP 设计是单店专用。换店需要：
1. 重新扫码登录（同一台机的 sessions 目录会冲突）
2. ~~重新配置 5 个 SKU 商品 ID~~（v1.5：sku_bootstrapper 自动从新店 g-list 同步，无需手动配置）
3. 等到路径 B（多店多平台支持）就不用切了

### Q9：决策日志能删除吗？

A：**不能删除**，只能改状态（pending/adopted/rejected/postponed）。这是命中率追踪的基础——删了就没法跟踪 AI 准不准。

### Q10：能不能让某天不要跑？

A：可以。在 `/scout` runbook 详情里设「明天暂停」 → 系统跳过那天。

### Q11（v1.5）：我有个 SKU 不在重点池，但我特别想盯它怎么办？

A：到那个 SKU 的详情页，右上角点 ⭐ "**锁定为重点池**"。这个 SKU 会立即进入重点池开始跑深度抓取（罗盘 product-detail + 云图 SPU 5A + 商品级心智）。锁定上限是 5 个 SKU，下次"主推/衰退/新品" 9 个 + 你锁定的 5 个 = 最多 14 个进重点池。点 ⭐ 取消锁定即恢复规则化判断。

### Q12（v1.5）：重点池里的 SKU 我看着不对，能否人为改规则？

A：不建议人为改规则。规则是**透明可见**的（GMV TOP 5 + 衰退 TOP 2 + 新品 TOP 2），每周日重排。如果某个 SKU 你坚持要盯就用 Q11 的"锁定"；如果你觉得规则本身不合理（比如新品阈值想从 30 天改 45 天），告诉研发改 `focus_pool_builder.py` 一行常量。

### Q13（v1.5）：我没配企微，会不会错过重要告警？

A：不会。系统默认走 **站内通知 + 浏览器原生通知**——只要你打开过 omni-vibe 一次允许浏览器通知，**即使 omni-vibe 不在前台你也能在 Windows 通知中心看到**。企微只是补充通道，等以后想要再加。

## 八、关键术语对照（v1.5）

| 你看到的 | 含义 |
|---|---|
| 巡店 | 系统自动从三平台（罗盘+抖店后台+云图）抓数据 |
| **重点池**（v1.5）| 系统自动选出的 ~9 个 SKU（5 主推 + 2 衰退 + 2 新品）做深度抓取；非重点池只跑核心日报 |
| **锁定**（v1.5）| 老板手动钉到重点池的 SKU（最多 5 个），系统额外加入 |
| **NotificationChannel**（v1.5）| 通知抽象层：站内 / 浏览器原生 / 企微 / 邮件 4 通道，按 .env 配置自动启用 |
| Runbook | 一份"巡店任务"（v1.4 共 8 份：A 全店日报 / B SKU 详情 / C 客服与原声 / D 搜索流量营销 / E 人群与机会 / F 物流与履约 / G 品牌心智 / H 品牌资产+触点）|
| 异动 | 数据出现明显变化（紧急 / 警告 / 正向）|
| 动作（change event） | 你做的或系统替你抓到的变更 |
| 双轨动作日志 | 用户登记（轨 A）+ 系统从平台抓取（轨 B） |
| 决策日志 | AI 给你的建议存档 |
| 验证（verification） | 动作执行 7 天后系统跑的前后对比 |
| Verdict | 验证结论：正向 / 负向 / 中性 / 无法归因 |
| 命中率 | AI 建议中"采纳后产生正向效果"的比例 |
| SKU | 你的产品（路径 A 阶段对应抖店商品 ID） |
| **5A 模型** | 云图概念：消费者从机会到拥护的 6 个阶段（O 机会 / A1 了解 / A2 吸引 / A3 问询 / A4 行动 / A5 拥护）|
| **6 场景流转** | 5A 之间的 6 种关键流转：拉新 / 蓄水 / 种草 / 直播转化 / 种草转化 / 复购 |
| **品牌心智** | 联想量 / 美誉度 / 偏爱度，云图度量品牌"非交易"健康度 |
| **5A 心电图** | 工作台首页顶部 6 张大卡 + 5A 趋势 3 指标的可视化（Dwell/Connection/Increase）|
| **6 场景化策略卡** | 工作台 6 张卡，每张对应一个 5A 场景的"今天该做什么"建议 |
| **6 待办数** | 抖店后台首页 6 个红点数字（待发货/待售后/待评论/待审核/异常/申诉），实时抓取 |
| **行业排名 / 对比品牌均值** | 云图独有 benchmark（如商品行业排名 1732 / 你的 5A 资产对比品牌均值）|
| **超过同行 X%** | 你的某项数据在同行业品牌中的位置（如 A3 问询超同行 74.7%）|
| **触点效能** | 云图度量你的投放结构（通投/UGC/品牌广告/达人营销 占比）——MVP 用来部分替代千川数据 |
