## 二、路径 A → 路径 B 的迁移日

### 2.1 升级当天（约 1 小时）

研发会做：
- 数据迁移（路径 A 5 SKU + 所有数据 → omni_*）
- Sidebar 改版
- 旧 URL 自动重定向

**你需要做**：

1. 用现有抖店账号扫码登录确认（5 分钟）
2. 用天猫账号首次扫码登录（5 分钟）
3. 用京东账号首次扫码登录（5 分钟）
4. 录入更多 SPU（可选，5-30 分钟，详见 §3）

### 2.2 录入 SPU（可选但推荐）

路径 B 可以管理任意数量 SPU。建议第一周扩到 20-30 个核心 SKU。

**怎么录**：

- 路径 1：手动添加
  ```
  /products → 「+ 新建 SPU」→ 填名称、类目
  → 「+ 添加平台链接」 → 选店铺 + 输入平台商品 ID
  ```

- 路径 2：CSV 批量导入
  ```
  下载模板 → 填好 → /products 上传 → 系统尝试自动映射各平台 SKU
  → 你确认 / 修正映射 → 保存
  ```

## 四、SKU 详情页 7 Tab 怎么用

打开任意 SKU（路径：`/sku/[id]`，或从 `/products` 点击进入）。

### 4.1 概览（默认视图）

**全景视角**：

```
顶部：SPU 信息 + 三平台总 GMV + 综合状态徽章

中间：三平台对比卡
  抖店  35 万 ↑12%   |  天猫  22 万 ↓8%   |  京东  11 万 ↑3%

底部：
  - 最近 7 天动作（≤5 条）
  - 待你处理的 AI 建议（≤3 条）
  - 最近异动列表
```

**怎么用**：5 秒内能判断这个 SKU 整体状态。

### 4.2 资产 Tab

**资产版本树**（按平台分组）：

```
抖店：
  📷 主图：v1（旧）→ v2（4/15 改：突出零添加）→ v3（4/26 改：场景图）
  📄 详情页：v1 → v2（4/22 改：加用户实拍）
  💰 价格：19.9 → 16.9（4/20 限时）
  🎬 视频素材：[vid_001, vid_002, vid_003 ...]
  🎯 人群包：[云图_母婴宝妈, 云图_健康养生]

天猫：
  📷 主图：...（独立版本树）
  ...

京东：
  ...
```

**怎么用**：
- 看每个资产的版本历史
- 点击任意版本 → 看截图大图 + 上线时间 + 关联的动作
- 每个资产「v1 vs v2」可以一键对比效果

### 4.3 数据 Tab

**多维度趋势图**：

```
默认显示 14 天，可调到 7/30/90 天
默认 4 条线：GMV / UV / CTR / CVR
可单独切换/叠加
跨平台对比模式：每条指标 3 条线（一平台一色）
动作变更竖线叠加：鼠标悬停看动作描述
```

### 4.4 动作 Tab

**完整动作时间轴**：

```
最新 → 最旧
每条动作显示：
  - 时间 / 平台徽章 / 资产类型图标
  - 描述
  - 截图缩略图
  - 验证状态徽章（pending / running / verified-positive / verified-negative）
点击展开：完整描述 + 截图大图 + 前后对比卡
```

**多平台同步动作**：用 `cross_platform_group_id` 聚合显示为 1 条（标"三平台同步"）。

### 4.5 AI 诊断 Tab

**与本 SKU 相关的所有 decision_log**：

```
顶部：
  「+ 启动深度诊断」按钮（触发圆桌 + 全维度数据）

列表：
  按时间倒序，显示：
    - 来源徽章（roundtable / scout_anomaly / ad_review / ...）
    - 类型徽章（diagnosis / suggestion / anomaly）
    - 状态徽章
    - 适用平台标签（["douyin", "tmall"]）
    - 标题 + 摘要
  
  操作：采纳 / 拒绝 / 暂缓 / 展开看完整内容
  
  采纳后系统自动建 change_event 草稿（预填全部字段，你只需确认 + 上传截图）
```

### 4.6 内容 Tab

**content-studio 关联的物料**：

```
- Brief 列表（点击进入 content-studio brief 详情）
- 视频素材列表（按平台、按版本）
- 短视频脚本列表
- 数字人脸库引用
```

### 4.7 客服 Tab

**评价 + 客服会话 + 痛点分类**：

```
左侧：
  评价摘要（按平台分组，按好评/差评分类）
  最近 7 天痛点 word cloud
  痛点趋势图（哪类问题在增加）

右侧：
  客服会话列表（脱敏）+ LLM 摘要
  
底部：
  自动生成的"基于客服痛点的优化建议"（系统自动写 decision_log）
```

## 五、Focus Context 工作焦点

### 5.1 怎么进入焦点模式

任意 SKU 列表 → 鼠标悬停某 SKU → 出现"设为焦点"按钮 → 点。

或者：直接进入 SKU 详情页时自动设为焦点。

### 5.2 焦点状态下你看到什么

**任何页面顶部都有 FocusBar**：

```
[🎯 当前焦点：零添加生抽 500ml | 抖店 | 退出焦点 ✕]
```

### 5.3 焦点模式下的智能注入

| 模块 | 自动行为 |
|---|---|
| chat | 提问框预填"关于 [焦点 SKU]，..." 提示词 |
| 圆桌讨论 | 默认议题填"针对 [焦点 SKU] 的优化策略" |
| content-studio brief | 默认挂载焦点 SKU |
| ad-review 新建复盘 | 默认选择焦点 SKU |
| 异动卡片 | 焦点 SKU 的异动会高亮 |

### 5.4 退出焦点

- 顶部 FocusBar 点 ✕
- 按 Esc 键
- 关闭浏览器（焦点持久化到 localStorage，重开后还在）

## 六、Send to 跨模块流转

### 6.1 典型场景

**场景 1：圆桌讨论结果 → 内容 brief**

```
你：跟 AI 圆桌讨论"零添加生抽爆品策略"
讨论结束 → 主持人总结
你：点右上角 → → 「用作内容 brief」
系统：跳到 content-studio 新建 brief 页面
     - 标题、目标、卖点全部从圆桌总结预填
     - 关联 SPU
你：略改几个字 → 保存
```

**场景 2：异动诊断 → 派发动作项**

```
工作台异动卡片 → 进 SKU 详情 → 启动深度诊断
诊断结束 → 一条具体建议（比如"换主图突出零添加"）
你：点该建议右侧 → → 「派发为动作项」
系统：建一条 change_event 草稿，预填：
  - SKU
  - 平台（建议中说明的）
  - asset_type = main_image
  - 优化意图、期望 KPI
你：去抖店改主图 → 回来确认 + 上传截图
```

**场景 3：知识问答 → 创建投放复盘**

```
你：在 chat 问"上次 4/15 投放期数据怎么样？"
AI：基于 RAG 给出回答
你：点 → 「创建投放复盘」
系统：跳到 ad-review 新建页面，预填上下文
```

### 6.2 5 个目标速查

| 目标 | 用途 |
|---|---|
| 📋 决策日志 | 默认强制存档（不点也会存） |
| 🎬 内容 brief | 派发到 content-studio 生成内容 |
| 🎯 投放复盘 | 派发到 ad-review 做复盘 |
| ✍️ 动作项 | 直接建 change_event 草稿 |
| 📦 关联 SKU | 把这条 AI 输出关联到某 SKU 详情 |

## 七、决策日志中心怎么用

### 7.1 日常使用

```
入口：sidebar 📊 数据与归因 → 决策日志（或 /insights/decisions）

顶部 Dashboard 卡：
  - 待处理 (X) | 已采纳 (X) | 已验证 (X) | 命中率 X%
  - 本周新增 X 条 | 上周 X 条 | 趋势 ↑↓
  
筛选栏：
  - 状态：全部 / 待处理 / 已采纳 / 已拒绝 / 已暂缓 / 已验证
  - 类型：全部 / 诊断 / 建议 / 异动 / 实验
  - SKU：全部 / 选某 SPU
  - 平台：全部 / 抖店 / 天猫 / 京东
  - 来源：全部 / 圆桌 / 异动 / 投放复盘 / 手动诊断
  - 时间：今天 / 本周 / 本月 / 自定义
  
搜索：标题 + 摘要全文搜索

列表：每条决策卡，操作按钮（采纳/拒绝/暂缓/展开）
批量：勾选多条 → 顶部出现批量操作栏
```

### 7.2 命中率怎么看

```
连续 4 周 ≥ 60% 命中率 → 飞轮转得起来
低于 50% → 需要调整：
  - 是 AI 给的建议太空泛？→ 调圆桌 prompt
  - 是建议没采纳到位？→ 调你自己的判断
  - 是采纳后执行不彻底？→ 流程问题
```

## 八、周度 Dashboard

### 8.1 周日 21:00 进 `/insights/weekly`

会看到：

```
顶部 KPI（4 张卡）：
  本周 GMV / 本周 UV / 本周 CVR / AI 命中率

中段 6 张图：
  1. GMV 7 日 / 28 日趋势（4 条线）
  2. SKU 涨跌热力图（每个 SKU 一格，颜色深浅 = 涨跌幅度）
  3. 三平台 ROI 对比（柱状）
  4. 动作-数据时间轴叠加（动作竖线 + GMV 曲线）
  5. AI 命中率分布（饼图：positive / negative / neutral / 待审）
  6. 客服痛点 word cloud + 趋势

底部归档：
  - 顶部成功案例 (≤3 条)
  - 顶部失败教训 (≤3 条)
  - 待处理决策 ([X] 条 → 点击进决策日志)
  
工具栏：
  - 「导出 PDF 周报」按钮
```

### 8.2 5 步复盘

1. 看 KPI：本周整体好不好？（30 秒）
2. 看 SKU 热力图：哪些 SKU 涨/跌最多？（1 分钟）
3. 看动作-数据叠加：跌的 SKU 是因为做了什么？涨的是什么动作起的作用？（5 分钟）
4. 看命中率：AI 这周建议准不准？（1 分钟）
5. 看客服痛点：用户在抱怨什么？（3 分钟）
6. 处理 pending 决策 → 写本周教训 → 归档成功案例（10 分钟）
7. 导出 PDF（30 秒）

**总计 30 分钟内完成。**

## 十、FAQ

### Q1：路径 A 的数据迁过来了吗？

A：是的。路径 A 的 5 个 SKU、所有指标、动作日志、决策日志都在路径 B 里继续可见。

### Q2：路径 A 的 sidebar 项不见了怎么找？

A：所有旧 URL 自动重定向到新位置。比如你输入 `/chat` 会跳到 `/intel/chat`。常用映射：

| 旧 | 新 |
|---|---|
| /chat | /intel/chat |
| /knowledge | /intel/knowledge |
| /ad-review | /marketing/review |
| /content-studio | /content/studio |
| /scout | /insights/scout |
| /decisions | /insights/decisions |
| /models | /system/models |

### Q3：怎么同时管理三平台的同一个产品？

A：在 `/products` 页面点 SPU → 「+ 添加平台链接」 → 选店铺 + 平台 SKU → 保存。之后系统自动把多平台数据归集到这个 SPU。

### Q4：跨平台对比的指标可以信吗？

A：以下指标可以直接对比：
- GMV、销量、客单价、UV
不要直接对比的：
- CTR、CVR（各平台定义有微差，但同一指标的趋势可比）
不可比：
- 各平台特有指标（抖店"内容曝光" vs 天猫"搜索曝光"）

### Q5：客服会话抓取会不会被风控？

A：跟巡店 runbook 一样的策略：随机延迟 + 真实浏览器 + 持久 storage_state。三平台分别单独抓取，频率每天 1 次（晚 22:00）。

### Q6：能让 AI 自动改主图吗？

A：路径 B **不开启自动执行**。AI 只给建议 → 你采纳 → 你去执行 → 系统验证。
未来路径 C 可能开放部分动作自动执行（如自动调价），但需要你明确授权 + 限额限制。

### Q7：决策能跨多个 SKU 吗？

A：每条决策只能关联 1 个 SPU（业务上更聚焦）。如果一条建议适用多个 SPU，建议拆成多条。

### Q8：成功案例归档后会怎么用？

A：归档的成功案例会被存到知识库 + 在未来圆桌讨论时**自动作为参考资料**注入。比如下次有新 SKU 类似情况，AI 会引用"上次 SKU-S001 主图改版后 CVR +50% 的案例"。

### Q9：失败教训会被 AI "学到"吗？

A：是的。失败教训也会存到知识库。AI 在给建议时会避免重复建议你已经标失败的方向。

### Q10：什么时候需要升级到路径 C？

A：当你需要：
- 多人/团队协作
- 移动端访问
- 库存/财务联动
- 自动执行动作（AI 直接改主图）
- 接入第四个平台

时，跟研发说"启动路径 C"。
