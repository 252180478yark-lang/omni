# 《02》人群包对比诊断说明书（怎么做 · 投前体检）

> 适用：量级已满意/已提纯的候选包，投放**之前**的可复用体检。
> 工具：`diagnose_audience_pack(candidate, baseline='baseline_a4')` 一句出投前诊断卡。
> 核心：逐维度算候选相对 A4 的指数，**比对看方向，不算总相似分**，嵌入 A4 真需求指纹锚。

## 0. 输入
- **候选包画像**：巨量引擎/云图人群分析导出 CSV（`标签类型,标签,占比,tgi`），丢进 `config/audience/`（或 `OMNI_AUDIENCE_PACK_DIR`），按文件名调；也可传绝对路径 / 原始 CSV 文本。
- **基准**：`baseline_a4`（内置行业 A4 = 一个月内真买过酱油的人，静态真需求标尺）。

## 1. 五维分类（工具内建，确定性映射）
| 维 | 含哪些标签类型 | 期望方向 | 读数 |
|---|---|---|---|
| **价值维（付得起）** | 预测消费能力 / 城市等级 / 手机价格 | **正向偏离 A4 高端尾部** | 贴近 A4 均值是反的（A4 价格敏感，最打不动）|
| **购买行为维（软硬）** | 电商消费金额(客单) / 电商消费频次 | 比 A4 软 = 种草信号（非扣分）| 定漏斗位 |
| **需求维（真需求）** | 电商品类成交/品牌 / 抖音头条西瓜兴趣 / 触点互动偏好 | **重叠 A4 真需求指纹** | 重叠高 = 真需求强 |
| **身份维（谁）** | 八大消费群体/年龄/性别/职业/人生阶段/地域 | **差异不计** | 构成不同 ≠ 质量缺口 |
| **噪音维** | 手机品牌 / 各端活跃用户 / 城市(过细) | 忽略 | — |

## 2. A4 真需求指纹锚（嵌在工具里当参照）
- **品类锚**：TGI 1300+（如 粮油米面南北干货调味品-米面粉杂粮/食用油调味油 等）。
- **兴趣锚**：TGI 220–280（抖音兴趣 v2：时尚/医疗/情感/运动 等）。
- **触点锚**：TGI 300–490（千川直播带货/短视频图文带货/企业号直播 等）。
- 候选在某锚 TGI ≥ 100（高于大盘均值）= 留住该真需求信号；留住率高 = 重叠强。

## 3. 输出：投前诊断卡（R-14 强制分层）
1. **观察到的**（客观，带数据，不含因果）：五维逐项候选 vs A4。
2. **漏斗定位**（价值方向 + 购买软硬 + 需求重叠 → 规则映射）：
   - 价值流失 → **慎投**（除非内容能撬动）；
   - 付得起 + 需求强 + 购买不软 → **即投/收割型**；
   - 付得起 + 购买更软/需求软 → **种草型**（内容从唤醒做起，收割别急）。
3. **内容策略定调**（假设·非断言，每条带"要证实需对比真实转化"；polish 时巨量云图 KB grounding）。
4. **提纯施工单**（with_purify_plan=True 时附，见《01》）。
5. **口径与样本量警示**：**画像是投前冷启动代理，判断不了真实投放价值**——按定调小预算测，看 CTR/CVR/ROI 再放量。

## 4. 调用
```
diagnose_audience_pack(candidate="diyu_xunwei")                       # 纯确定性诊断卡
diagnose_audience_pack(candidate="X", polish=True, focus="主推健康")   # + 巨量云图 KB grounding 小白叙事
```
范例：地域寻味人 → 价值维正向偏离高端 + 购买行为更软 + 需求重叠强（核心调味品锚留住）→ **种草型**。

## 5. 铁律
- A4 = 真需求标尺，**不是提纯工具、不是模仿对象**；身份维差异不扣分。
- 比对**看方向，不算总相似分**（一个总分会把"高端增益"和"价值流失"抹平）。
- 诊断的是**最终真投出去那个包**——大包先用《01》提纯，再用《02》诊断。
