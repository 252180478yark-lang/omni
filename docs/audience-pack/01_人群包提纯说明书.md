# 《01》人群包提纯说明书（怎么做 · 把大包收窄）

> 适用：候选包量级过大（数千万）要收窄到目标量级（200–1000 万）。**A4 不参与提纯**。
> 工具：`diagnose_audience_pack(candidate, with_purify_plan=True)` 自动出《提纯施工单》。
> 配合：提纯**之后**再用《02》诊断（诊断的是最终真投出去那个包，不是原始大包）。

## 0. 原则（先记死）
- **提纯靠"商品 + 圈层"逻辑，不靠 A4**。A4 是真需求标尺，不是提纯工具。
- **哪条轴切错不可逆，就在那切最狠**：对和田宽 = **付得起**（价格敏感内容补不了，切到死）；需求轴内容能改造，**留松**。
- **"已购买"是收割层 filter，不是种草包 filter**：切到"会下厨/相邻行为"为止，**不切到"已买酱油"**。
- 切完的新开发细分（A4 查无此人）= 假设，先小预算测，转化了再放量。

## 1. 三刀法（工具按此出施工单，每刀落到真实可勾的巨量云图标签）

### 第一刀 · 价值/付得起（切到死）
- 只留高端尾部：`数据工厂 → 预测消费能力 → 高消费`、`数据工厂 → 城市等级 → 一线城市 + 新一线城市`、`数据工厂 → 手机价格 → ≥5000 档`。
- 理由：付得起内容补不了，价格敏感的人是和田宽最打不动的，切到死不可惜。

### 第二刀 · 需求相邻（切到"会下厨"，不切到"已买酱油"）
- 交集核心品类/兴趣 over-index 锚：`数据工厂 → 电商品类成交偏好 → 粮油米面南北干货调味品-食用油调味油 / -米面粉杂粮`、`抖音/头条兴趣 → 美食 / 育儿`等候选包留住的真需求锚。
- 理由：需求轴内容能改造，留松；切到相邻烹饪/下厨行为为止，别切到"已购酱油"（那是收割层）。

### 第三刀 · 内容亲和（收紧）
- 按高 TGI 触点收紧：`数据工厂 → 触点互动偏好 → 千川直播带货 / 千川短视频图文带货`等。
- 目的地：云图**数据工厂 → 关键词夹 → 新建关键词包**，或自定义人群的交并差，最后推千川。

## 2. 操作落地（人群 → 人群列表 → 新建人群）
1. 巨量云图 **人群 → 人群列表 → 新建人群**：以候选大包为起点。
2. 按三刀施工单，在 **数据工厂** 里逐维度勾选 / 交并差（∩ 交集、∪ 并集、- 排除）收窄。
3. 量级看新建人群预估规模，收到目标量级（200–1000 万）即可。
4. 推千川。

> **小白可操作版**：`diagnose_audience_pack(candidate, polish=True)` 把每刀写成"在哪个面板、点哪个一级>二级>三级、勾哪个标签、为什么"的大白话步骤（巨量云图标签体系 KB grounding）。

## 3. 收尾
- 提纯后量级合适 → 立刻用《02》（`diagnose_audience_pack` 再跑一次提纯后的包）做投前诊断。
- **切量会改变需求成色**，所以诊断必须放在提纯之后。
