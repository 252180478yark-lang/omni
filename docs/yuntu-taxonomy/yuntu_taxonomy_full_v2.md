## 一、数据工厂 · 标签工厂（dump 抓不到的海量树，本字典核心补全）

后台路径：**云图 > 数据工厂 > 标签工厂 > 新建标签**。
先选**标签类型**（决定下面填什么），再选数据源/行为/品类/词包，保存等计算（几小时变绿后可用），最后回**自定义人群**里引用这个新标签。

### 1.1 标签工厂建标签 · 字段全集（5 个必填字段，建任何标签都按这个填）

| 字段 | 可选项 | 说明 |
|---|---|---|
| **标签类型** | ① 内容标签 ② 人群标签（a 内容人群标签 / b 商品人群标签 / c 搜索人群标签）③ 达人标签 | 决定下面字段；圈"买过某品类/品牌"→ 商品人群标签；圈"搜过词"→ 搜索人群标签；圈"看过内容"→ 内容人群标签 |
| **数据源端** | 抖音 / 今日头条 / 西瓜视频 / 抖音火山版（多选）| 食品调味品默认勾**抖音**，要拓量再加头条/西瓜 |
| **数据源种类** | 内容标题·视频语音·视频字幕（内容标签）；商品标题（商品人群标签）；搜索词（搜索人群标签）| 随标签类型自动锁定 |
| **用户行为** | 内容：有效播放·点赞·收藏(仅头条)·评论·转发；商品：曝光·点击·浏览·加购·购买；搜索：搜索行为 | 多选 |
| **频次 + 时间窗** | ≥1/≥3/≥6 次 × 近 7/14/30/60/90 天 | 越宽量越大、越窄越精准 |
| **匹配方式**（内容标签）| 规则匹配（含词即算，准但漏）/ 内容理解（语义近似也抓，广，默认推荐）| 语义近似场景用内容理解 |

**行为定义（真实口径）**：有效播放=视频≥5s/文章阅读≥10s；曝光=商品锚点曝光；点击=点商品锚点；浏览=进商详页；加购=加购物车；购买=支付订单数（**含退款单**）。

**命名规范**：`<人群核心词>-<标签类型>-<时间窗>-<频次>`，如「有机调味-商品购买-30D-≥1次」（方便后续在自定义人群里认）。

## 三、人群 > 人群列表 > 新建人群（操作骨架 + 交并差 + 推千川）

### 3.1 新建人群（小白照点）

1. 进 **云图 > 人群 > 人群列表 > 右上角「新建人群」**（即自定义人群）。
2. 中央工作区按维度勾（§二的标签）：每个维度勾完会显示"预计覆盖人数"。
3. 多维度之间默认是**交集（AND）**——勾的条件越多人越少越精准。
4. 需要"近30天搜过/看过/买过X"这种行为标签 → 先去 §一 数据工厂标签工厂建好，再回这里在对应维度里**引用**这个新标签。
5. 起名（带核心特征，如「有机调味-中产-30D」）→ 看量级 → 保存。

### 3.2 多个人群再组合（人群列表 > 新建组合人群）

| 运算 | 含义 | 后台 | 干啥 |
|---|---|---|---|
| 交集 ∩ | 同时满足 A 和 B | 人群组合 > 交集 | **收窄/提纯**（爱看美食 ∩ 资深中产 = 又爱看又买得起）|
| 并集 ∪ | A 或 B 任一 | 人群组合 > 并集 | 扩量（多个相邻人群合并）|
| 排除 − | A 但不 B | 人群组合 > 排除 | 去重/剔老客（最终包 − 已购人群 = 只触达新客）|
| 拓展 lookalike | 种子找相似人 | 人群管理 > 相似人群拓展 | 量太小时拓 1x/2x/5x |

## 四、人群包提纯：用标签收窄人群的三刀法（给"提纯人群包"场景用）

提纯 = 一个太宽/太杂的人群包，用标签**砍掉买不起、不相关、不对路的人**，留下"最可能下单"的核心。落到本字典的具体可勾标签，三刀法如下：

### 第一刀：付得起（消费力收窄）

- **加交集**：§2.1 `八大消费群体`（勾资深中产/新锐白领/精致妈妈）+ `预测消费能力`（中等/高消费）+ `电商消费金额`（勾高档位如 (300,500]/(500,1000]/(1000,+∞)）+ `手机价格`（勾 3000 元以上档位，侧证消费力）。
- **大白话**：高客单调味品别投低消费人群，先把"买得起"的圈住。

### 第二刀：需求相邻（品类/品牌邻近收窄）

- **加交集**：§1.2 `电商品类成交偏好`——勾买过相邻品类的人（如 `粮油米面南北干货调味品 > 食用油调味油 / 调味品果酱沙拉`、`奶粉辅食营养品零食 > 婴童调味品`、`保健食品膳食营养补充食品`、`水果蔬菜`、`肉蛋低温制品`——做饭/讲究吃的人）。
- 或 §1.3 `电商品牌成交偏好`——勾买过同类/高端调味品牌的人。
- **大白话**：买过同类品的人需求最近，转化率最高，优先留。

### 第三刀：内容亲和（兴趣/题材收窄）

- **加交集**：§2.2 `抖音视频观看分类`——勾 `美食 > 制作美食/日常美食展示`、`生活 > 生活探店/日常活动`、`亲子 > 母婴`（看做饭/家庭/育儿内容的人，跟调味品内容亲和）。
- **大白话**：留下平时就爱看做饭/家庭内容的人，素材推给他们不违和。

### 提纯组合示意

```
原始宽包  ∩ [第一刀:付得起标签]  ∩ [第二刀:相邻品类/品牌]  ∩ [第三刀:内容亲和]
           − [排除已购老客]   = 提纯后的高潜核心包
```
> 三刀不必都用——量够就少砍，量不足先松第三刀。每砍一刀看一次"预计覆盖人数"，砍到量级既够投又够准为止。

## 五、使用约束（给 LLM 出 SOP 时）

1. **禁止虚构**：所有标签名/层级只能从本字典 + dump v1 字典里选；没有就写"建议老板在云图后台『XX 菜单』搜实际可选项"，不脑补。
2. **粒度到二级/三级**：电商品类优先勾到二级（如"食用油调味油"而非只到"粮油米面…"）；抖音兴趣优先勾到二级（如"美食>制作美食"）。
3. **认清入口**：电商品类/品牌成交偏好 → 走数据工厂标签工厂建商品人群标签，**不在自定义人群创建页直接勾**。
4. **官方命名唯一权威**：八大消费群体（非"八类人群"）、Z世代（非"90后"）、精致妈妈（非"都市妈妈"）。
5. **更新**：电商品类/品牌树来自真实人群画像反查，云图后台季度可能微调，完整最新树需老板手动从标签工厂导出/截图核对（见报告 T2）。
