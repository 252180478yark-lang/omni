# rubric · generate_creative_pack（step 5 创意素材，video_* 优先）

> 产物 = 视频类脚本（video_soft_ad / video_planting / video_harvest）：方法论判定 + 共鸣点 +
> 主脚本 + 钩子变体 + 分镜清单 + metrics_json。
> 评审基线：和田宽打不了价格战，靠"用户喜欢的内容→软植入→种草→收割"；
> 软广（A2）禁直接卖货话术，收割（A4）禁编假销量/假库存。

## 维度

### 钩子强度
- 5：3 个钩子变体前 3 秒都有明确停指理由（冲突/悬念/共鸣暴击），角度互不重复，口语自然
- 3：钩子能用但角度雷同或力度平（"你家酱油选对了吗"级别）
- 1：钩子是产品介绍开场或套话开头（"宝子们"），留不住人

### 卖点植入自然度（按 kind 的漏斗位置）
- 5：植入方式匹配漏斗位置——soft_ad 产品完全融入剧情当道具、planting 痛点引出卖点不突兀、harvest 卖点+CTA 直给但不编假数据；卖点全部源于上游矩阵/SKU 真实字段
- 3：植入基本对位但有 1-2 处生硬转场（"说到这里不得不提"）
- 1：soft_ad 出现叫卖、harvest 编了假销量/假限量，或卖点是编的

### 分镜可拍性与节奏
- 5：分镜数量符合 kind 时长规格，每镜有画面/动作/时长，单镜 ≤ 8s，镜头切换节奏服务情绪曲线（前热中稳尾翘）
- 3：分镜齐全但个别镜偏长或画面抽象需二次翻译
- 1：分镜缺失/超时长规格/全是静态口播

### 人群对味度
- 5：题材、场景、人物、梗都踩在挂入的人群画像上（生活场景/触媒习惯/情绪底色），不是泛大众内容
- 3：方向对但只用到人群画像的表层（年龄/身份），没用到生活状态细节
- 1：内容与人群无关，换个人群也能用（通用模板感）

### 反 AI 腔与真实感
- 5：台词像真人说话（有口头禅、有停顿、不完整句），场景有生活毛边（杂物/油渍/背景音）；无禁用词无套话
- 3：基本自然，偶有书面台词或过于干净的摆拍感
- 1：台词是文案腔（"开启品质生活"），或出现禁用词/AI 套话
