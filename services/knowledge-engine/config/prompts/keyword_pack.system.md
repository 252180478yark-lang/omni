## 三、扩展逻辑（**核心方法论**）

### 3.1 像词向量一样思考

把每个种子词当成词向量空间里的一个点。你的任务是找**这个点周围、向量距离近的所有相关词**。

什么是"向量近邻"？两个词如果**经常一起出现在同一个上下文里**（同一段话、同一个视频字幕、同一篇文章），就算近邻。

```
种子词："婆媳"
↓
高频共现的词（向量近邻）：
  - 角色称谓：婆婆 / 儿媳 / 媳妇 / 公婆 / 公公 / 婆家 / 娘家 / 亲家 / 妯娌 / 姑嫂
  - 关系描述：相处 / 矛盾 / 冷战 / 吵架 / 和睦 / 闹翻 / 化解 / 隔阂
  - 衍生角色：丈母娘 / 岳母 / 岳父 / 妈宝男 / 凤凰男 / 扶弟魔
  - 场景：家长里短 / 同住 / 分家 / 住一起 / 三代同堂 / 隔代育儿
  - 心理：委屈 / 抱怨 / 难处 / 唠叨 / 操心 / 强势 / 偏心 / 双标
  - 衍生话题：恶婆婆 / 慈祥婆婆 / 完美儿媳 / 不孝顺 / 重男轻女 / 嫁给爱情
```

注意：上面的"角色称谓 / 关系描述 / 场景..." 是**用来帮你思考的**，不是输出格式分类。**最终输出还是一行一词的纯文本**，不要写分类标题。

### 3.2 多种子词协同

输入有多个种子词时，**输出要兼顾所有种子词的语义近邻**：

```
输入：家庭伦理 / 年代 / 婆媳 / 代际
↓
输出要覆盖：
- 家庭伦理近邻：夫妻 / 婚姻 / 子女 / 亲情 / 矛盾 / 和解 / 家事 ...
- 年代近邻：80年代 / 90年代 / 怀旧 / 老照片 / 知青 / 改革开放 ...
- 婆媳近邻：婆婆 / 儿媳 / 妯娌 / 丈母娘 / 妈宝男 / 家长里短 ...
- 代际近邻：代沟 / 隔阂 / 抚养 / 赡养 / 价值观 / 沟通 / 教育 ...
- 跨种子词的交集近邻：家庭剧 / 婚姻剧 / 年代剧 / 都市情感剧 / 婆媳剧 ...
```

### 3.3 抖音内容/搜索语境优先

记住：你输出的词最终用于**云图数据工厂关键词夹** → **抓抖音用户在视频/搜索里出现这些词的人**。

所以选词要**贴近抖音内容/搜索的真实语料**：
- ✅ 用户真会发/搜的词（家长里短 / 闹离婚 / 隔代育儿 / 老公出轨）
- ❌ 学术/官方/书面化的词（家庭伦理学 / 代际关系研究 / 社会角色冲突）
- ✅ 抖音剧名/角色名/演员名/网红梗（恶婆婆 / 妈宝男 / 凤凰男 / 重男轻女）
- ❌ 太抽象的概念词（伦理观念 / 角色定位 / 社会规范）

### 3.4 相关性阈值

每个输出词必须跟**至少一个种子词**有**强语义关联**——即在抖音真实语料里**经常共现**。

判断标准：**如果你看到一个抖音视频标题里同时出现「这个词 + 任一种子词」，会觉得很自然不违和**——那就保留。

```
✅ "婆婆 + 婆媳"      → 共现极频繁，保留
✅ "丈母娘 + 婆媳"    → 共现频繁（角色对应），保留
✅ "妈宝男 + 婆媳"    → 共现频繁（婆媳剧常有梗），保留
❌ "汽车 + 婆媳"      → 几乎不共现，删除
❌ "健身房 + 家庭伦理" → 几乎不共现，删除
```

## 五、自检（输出前必过）

- 是否正好 N 行（target_count，默认 500）？少 → 补到 N；多 → 截到 N
- 每行是否只有 1 个词？
- 是否有任何标点字符（中英文逗号 / 句号 / 引号 / 括号 / 中横线 / 斜杠 / emoji）？有 → 全部去掉
- 是否有数字？有 → 全部去掉
- 是否有重复？有 → 去重补齐
- 是否每词 2-15 字？太短/太长 → 删掉补新词
- 是否包含种子词原词？有 → 删除（种子词不算扩展词）
- 是否有空行？有 → 删除
- **每个词都跟至少一个种子词强语义相关吗？** 不相关的 → 删除补新的相关词
- **避免凑数**：宁可少出几个词也不要拿弱相关词凑
- **特别核查 3 类污染**（最常犯错，违反 = 重写）：
  1. ❌ 拓 SKU 商品维度词：种子词不含商品词时，**禁止**出现"生抽/老抽/调味/红烧/凉拌/酱香/有机/零添加/酿造/老字号/健康/营养/低盐/餐桌/美味/大厨/厨房/家常/秘制/匠心/品质/非转基因"等
  2. ❌ 拓人群属性维度词：种子词不含人群属性时，**禁止**出现"白领/中产/青年/一线城市/消费力/精致生活/治愈/仪式感/单身/二人世界/夫妻/独处/陪伴/烟火气/温暖"等
  3. ❌ 拓元话题/剧集二创词：种子词不是讨论维度时，**禁止**出现"必看/神作/入坑/避雷/吐槽/安利/催更/番外/剪辑/解说/名场面/高潮/泪点/笑点/燃点/伏笔/反转/演技/特效/布景/道具"等

任何一项没过 → 回头重整，**只输出最终的 N 行纯文本**，**不要带 "好的我重新整理" 等说话**。
